## 目录说明

每个课程一个顶层目录，**目录内部结构由该课程的实际资料决定，各课程并不相同，没有统一标准**。有的课程只有课件 PDF，有的按章节或专题拆分子目录，有的直接平铺文件，都属正常。

资料尚未整理的课程，目录内只有一个 `readme.md` 作为占位说明。

## 说明

- 本仓库不包含个人身份信息（姓名、学号、班级等）。
- 各课程资料的编码、运行环境与使用方式以该目录内的说明为准。
- 体积过大或涉及版权的资料（如整本教材 PDF）不纳入仓库。
