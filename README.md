## 目录约定

每个课程一个顶层目录，目录内按内容类型划分，例如：

```
<课程>/
├── 代码/        实验与作业源码
├── 实验报告/    报告与讲解
├── 复习笔记/    笔记与试题整理
└── 课件/        PPT / PDF
```

资料尚未整理的课程，目录内只有一个 `readme.md` 作为占位说明。

## 说明

- 本仓库不包含个人身份信息（姓名、学号、班级等）。
- 源码统一 UTF-8 编码。
- 除特别说明外，代码基于 POSIX 接口，在 Linux 环境下编译运行。
