# 计算机安全

吉林大学计算机科学与技术专业《计算机安全》课程资料。

## 内容

- `课程PPT/`：课堂讲义，含访问控制模型（AC / RBAC / ABAC）、入侵检测、Linux 安全基础、SetUID、环境变量、缓冲区溢出、Return-to-libc 与 ROP/JOP、格式化字符串、竞态条件、DirtyCOW、量子密钥分发等
- `SEED计算机安全实验/`：SEED Labs 中文实验文档，按方向分六个子目录 —— 软件安全、Web 安全、密码学、网络安全、系统安全、区块链
- `前八章习题/`：课程习题中文翻译版、带答案与解析版
- `模式匹配算法/`：Boyer-Moore 算法图解教程、模式匹配算法图解
- `计算机安全课程手册_完整版.md` / `.docx`：课程知识手册
- `PPT中的小众细节问答题.docx`：课件细节问答整理
- `2026_计算机安全_期末考试说明.pptx`：期末考试说明
