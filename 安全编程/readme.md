# 安全编程

吉林大学计算机科学与技术专业《安全编程》课程资料。

## 内容

- 第 0–8 章课件（PPTX）：绪论、威胁建模、程序溢出、Socket 编程与 Socket 安全、并发及其安全、以最小特权运行、ShellCode 开发、死锁
- `安全编程知识点手册.pdf`、`安全编程知识点手册-完整版.pdf`：知识点整理
- `工具及代码/工具及代码/`：
  - `mysecur_programs/`：课程示例源码（C / C++），涉及 ACL 控制、备份权限、Socket 通信、栈检查、Token 操作等
  - `ActivePerl-*/`：配套 Perl 环境说明

> 编译产物（`.exe`）与第三方安装包（`.msi`）不纳入仓库。
